# 🧮 Calculadora em Python

## 📌 Sobre o projeto

Esse é meu primeiro projeto prático em Python! 🚀

Criei uma calculadora para praticar lógica de programação e colocar em prática o que estou aprendendo nos meus estudos. Durante o desenvolvimento, aprendi a trabalhar com operações matemáticas, estruturas condicionais e laços de repetição, além de identificar e corrigir erros no código.

## ⚙️ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔢 Potenciação (`**`)
- 📊 Resto da divisão (`%`)
- 🛡️ Verificação para evitar divisão e resto por zero
- ⚠️ Mensagem para operações inválidas
- 🔄 Opção para realizar vários cálculos sem precisar reiniciar o programa

## 💻 Tecnologias utilizadas

- Python

## 🧠 O que aprendi com esse projeto

- Utilizar variáveis para armazenar números e resultados.
- Receber informações do usuário com `input()`.
- Converter entradas em números usando `int()`.
- Utilizar `match/case` para selecionar a operação matemática.
- Trabalhar com `if`, `else` e `case _` para controlar as decisões do programa.
- Utilizar o operador `None` para representar a ausência de um resultado válido.
- Criar repetições com `while`.
- Entender a importância da indentação em Python.
- Identificar erros e aprender a corrigi-los durante o desenvolvimento.

## ▶️ Como executar

1. Instale o Python no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute o arquivo `calculadora.py`.
5. Digite os números e a operação desejada.
